# تطبيق مصنّف صور الاختبارات الجامعية (Exam Sorter)

تطبيق ذكي متكامل مبني بلغة بايثون باستخدام **Kivy** و **KivyMD 2.0**، يهدف إلى تصوير أو استيراد صور أوراق الاختبارات والمستندات الدراسية، والتعرف التلقائي على اسم المادة الجامعية باستخدام الذكاء الاصطناعي (Claude Vision API) أو عبر التعرف الضوئي المحلي، ثم تنظيمها وترقيمها تسلسلياً في مجلدات مخصصة لكل مادة.

---

## المميزات الرئيسية
1. **التعرف الذكي بالذكاء الاصطناعي:** استخراج اسم المادة والمقرر الدراسي تلقائياً من ترويسة الورقة بواسطة نموذج Claude 3 Haiku مع ضغط الصور لتقليل استهلاك البيانات.
2. **بديل محلي دون إنترنت (Offline OCR):** دعم التعرف المحلي عبر Tesseract OCR في حال انقطاع الشبكة.
3. **دعم كامل للغة العربية:** معالجة اتجاه النصوص وتشابك الحروف (Reshaping & BiDi) مع خط "أميري" المدمج.
4. **تنظيم وتسمية احترافية:** إنشاء مجلدات لكل مادة وتسمية الصور تسلسلياً بالصيغة: `اسم_المادة_YYYY-MM-DD_01.jpg`.
5. **معرض مصور لكل مادة:** استعراض جميع اختبارات المادة مع إمكانية تكبير ومعاينة الصورة كاملة.
6. **يعمل على سطح المكتب (Windows / Mac / Linux) وأجهزة الأندرويد.**

---

## التشغيل على الكمبيوتر (سطح المكتب - دون إنترنت)

### المتطلبات الأساسية
* بايثون 3.10 أو أحدث.

### خطوات التشغيل:
1. تفعيل البيئة الافتراضية أو تثبيت المتطلبات:
   ```powershell
   pip install -r requirements.txt
   ```
2. تشغيل التطبيق مباشرة:
   ```powershell
   python main.py
   ```
   *يعمل التطبيق بكامل شاشاته وواجهاته ومميزاته المحلية (إدارة الملفات، الترقيم التسلسلي، عرض المواد، اختيار الصور، التعديل اليدوي) دون الحاجة لأي اتصال بالإنترنت.*

---

## إعداد مفتاح الذكاء الاصطناعي (Claude Vision API)
لتمكين التعرف التلقائي على أسماء المواد بالذكاء الاصطناعي:
1. افتح ملف `.env` في المجلد الرئيسي واكتب مفتاحك:
   ```env
   ANTHROPIC_API_KEY=sk-ant-api03-...
   CLAUDE_MODEL=claude-3-haiku-20240307
   ```
2. أو أدخل المفتاح مباشرة من داخل التطبيق عبر الضغط على أيقونة **الإعدادات ⚙️** في الشاشة الرئيسية.

---

## البناء والتثبيت على أجهزة أندرويد والمحاكي

### الطريقة: البناء السحابي المجاني عبر GitHub Actions (توفير الإنترنت 0MB)
بدلاً من استهلاك أكثر من 1.5GB من باقة الإنترنت في تنزيل أدوات Android NDK والـ SDK محلياً:
1. ارفع المشروع إلى مستودع GitHub خاص بك:
   ```powershell
   git add .
   git commit -m "Initial commit for Exam Sorter"
   git branch -M main
   git remote add origin https://github.com/USERNAME/exam-sorter.git
   git push -u origin main
   ```
2. تم تضمين ملف الإجراءات التلقائية جاهزاً في `.github/workflows/build_apk.yml`. سيبدأ البناء تلقائياً في سيرفرات GitHub السحابية مجاناً.
3. توجه لتبويب **Actions** في مستودعك، وقم بتحميل حزمة الـ APK الجاهزة (`ExamSorter-debug-apk`).
4. انقل الملف لهاتفك وثبته مباشرة، أو ثبته على المحاكي عبر:
   ```powershell
   adb install ExamSorter-1.0.0-debug.apk
   ```
