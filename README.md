# تطبيق «رتّب» (Rateb AI) - منظّم الوسائط والاختبارات الذكي

تطبيق متطور ومستقل مبني بلغة بايثون باستخدام **Kivy** و **KivyMD 2.0**، يجمع بين الفرز الأكاديمي الدقيق لأوراق الاختبارات الجامعية، والتنظيم الشامل لجميع وسائط الهاتف (الصور والفيديوهات) محلياً وبأعلى معايير الأمان وسرعة الأداء مع دعم كامل للذاكرة الداخلية وبطاقات الذاكرة الخارجية (MicroSD) عبر نظام Storage Access Framework (SAF).

---

## 🌟 المميزات الشاملة لمنظومة الوسائط الذكية

1. **الترتيب الإلزامي الصارم للأولويات:**
   - **المرتبة الأولى:** أوراق الاختبارات الجامعية والمقررات الدراسية ➔ تُفرز في `ExamSorter/[اسم المادة]`.
   - **المرتبة الثانية:** صوري أنا (باستخدام التعرف على بصمة وجه صاحب الجهاز) ➔ تُنقل إلى `الملفات المنظمة/صوري`.
   - **المرتبة الثالثة:** صور فيها أشخاص آخرون (زملاء، إخوة، أصدقاء) ➔ تُنقل إلى `الملفات المنظمة/صور الزملاء والإخوة`.
   - **المرتبة الرابعة:** فيديوهات مضحكة وطريفة (ريلز، تيك توك، ميمز) ➔ تُنقل إلى `الملفات المنظمة/فيديوهات مضحكة`.
   - **المرتبة الخامسة:** محاضرات ودروس وتعلم ودورات ➔ تُنقل إلى `الملفات المنظمة/محاضرات ودروس`.
   - **المرتبة السادسة:** أفلام ومسلسلات وحلقات ➔ تُنقل إلى `الملفات المنظمة/أفلام ومسلسلات`.
   - **المرتبة السابعة:** أغاني وأناشيد ➔ تُنقل إلى `الملفات المنظمة/أغاني وأناشيد`.
   - **المرتبة الثامنة:** أي ملف وسائط لم يحسم تصنيفه ➔ يُنقل إلى `الملفات المنظمة/خارج التصنيف`.

2. **بصمة الوجه المرجعية محلياً دون إنترنت:**
   - تدريب نموذج التعرف على وجه صاحب الهاتف عبر التقاط أو اختيار 3-5 صور مرجعية.
   - **قرار المعمارية والبديل المعتمد (ONNX vs Pure OpenCV + NumPy):**
     تم اعتماد نموذج استخراج التضمين الموضعي (512-dim Normalized Embedding) عبر OpenCV و NumPy. هذا البديل خفيف، فائق السرعة، ومضمون البناء والتشغيل بنسبة 100% على كافة أجهزة أندرويد بدون مشاكل NDK.
   - استخراج التضمين المكاني المتعدد عالي الدقة ومطابقته بـ Cosine Similarity مع عتبة حساسية قابلة للتعديل من الواجهة (50% - 90%).
   - تجربة فورية واختبار مباشر لأي صورة من الشاشة للتحقق من التعرف عليها قبل النقل.

3. **طبقة تخزين موحدة ودعم MicroSD / SAF (Unified Storage Architecture):**
   - كشف حقيقي لحالة الذاكرة الداخلية وبطاقة MicroSD مع فحص إمكانية الكتابة داخل مجلد مخصص وتجنب الفحص في جذر البطاقة.
   - دعم رسمي لنظام أذونات أندرويد الحديث عبر Storage Access Framework (SAF) وحفظ إذن المجلد بشكل دائم (`takePersistableUriPermission`).
   - استعلام MediaStore عبر معرفات آمنة و Content URIs مع دمج نتائج الذاكرة وتخطي المجلدات المحمية تلقائياً دون استثناءات.
   - هجرة تلقائية وآمنة لأي مجلدات تصنيف قديمة (مثل تحويل "محاضرات وتعلم" إلى "محاضرات ودروس" الموحدة دون فقدان أي بيانات).

4. **بوابة كشف أوراق الاختبارات والمستندات بالرؤية الحاسوبية (CV Document Detection):**
   - حماية صور أوراق الاختبارات الملتقطة بالكاميرا (مثل `IMG_*.jpg`) من السقوط في "خارج التصنيف".
   - خوارزمية فحص بصري هجينة عبر OpenCV تحلل: السطوع العام للخلفية البيضاء، انخفاض التشبع اللوني، نسبة كثافة الحبر والنصوص، والتوزيع الترددي للأسطر الأفقية.
   - تصنيف دقيق عبر Claude Vision في حال توفر اتصال، أو حفظ آمن في مجلد `اختبارات عامة` محلياً لحين تسمية المادة.

5. **تصنيف الفيديوهات الهجين (Hybrid Local + AI Fallback):**
   - فحص محلي فائق السرعة عبر الكلمات المفتاحية في مسار واسم الملف + المدة الزمنية + أبعاد الشاشة ونسب الطول للعرض.
   - في حال عدم الحسم محلياً، يتم استخراج الإطار الأوسط واستشارة Claude Vision API عبر نموذج سريع وموجز.

6. **النسخ الآمن افتراضياً (Safe Copy First) مع دعم النقل الاختياري:**
   - يعتمد التطبيق افتراضياً وضع **النسخ الآمن (`copy_only=True`)** لحماية صور وملفات المستخدم الأصلية من أي حذف أو تعديل أو فقدان.
   - يمكن للمستخدم من شاشة الإعدادات اختيار وضع "النقل الفعلي (Move)" لتوفير سعة التخزين إن رغب في ذلك.
   - **التحقق الصارم قبل الحذف في وضع النقل:** التأكد من وجود الملف في الوجهة وتطابق حجمه بالبايت تماماً قبل إزالة الأصل. في حال أي انقطاع أو عدم تطابق، يتم حذف الوجهة الناقصة وحماية الملف الأصلي دون أدنى مساس.
   - توثيق كل عملية في سجل تاريخي تفاعلي `transfer_history.json`.
   - زر **تراجع (Undo)** فوري داخل شاشة الإعدادات لاستعادة أي ملف نُقل بالخطأ إلى مكانه الأصلي فورياً.
   - **نظام تشخيص وأمان دائم:** تفعيل `faulthandler` وسجل `cosmosort_debug.log` لتسجيل أي خطأ، مع درع الملف السام (Poison File Shield) لاستبعاد أي ملف معطوب تلقائياً دون إيقاف الدفعة.

7. **خدمة المراقبة التلقائية اللحظية (Media Watcher Service):**
   - خدمة خلفية مستمرة (Foreground Service مع إشعار دائم) لمراقبة مجلدات الكاميرا والتنزيلات والواتساب والتليجرام.
   - التحقق من اكتمال كتابة الملفات (ثبات الحجم لمدة 1.5 ثانية) قبل نقلها لتفادي معالجة الملفات أثناء التصوير أو التحميل.

## 📱 شاشات التطبيق السبع (Architecture & Screens)

1. `HomeScreen`: لوحة التحكم المركزية، عرض المجلدات والمعارض المنظمة، إحصائيات سريعة، وبحث حي.
2. `CaptureScreen`: التقاط صورة جديدة بالكاميرا أو اختيار متعدد من المعرض.
3. `ClassifyingScreen`: مؤشر التحميل والتصنيف التلقائي الذكي.
4. `ConfirmScreen`: مراجعة وتعديل التصنيف مع اقتراحات سريعة.
5. `SubjectDetailScreen`: شبكة متجاوبة لاستعراض جميع صور وفيديوهات المجلد مع إمكانية المعاينة والحذف.
6. `PeopleSetupScreen`: شاشة التقاط وتدريب بصمة وجه صاحب الجهاز وتجربة التعرف الحية.
7. `SettingsScreen`: لوحة تحكم خدمة المراقبة التلقائية، إعدادات الذاكرة وSAF، الفحص اليدوي الفوري، وسجل العمليات مع إمكانية التراجع.

## 🧪 دليل الفحص الآلي (Testing Guide)

قم بتشغيل سكربت الفحص الشامل المدمج:
```powershell
python test_modules.py
```
*يتحقق هذا الاختبار من 10 وحدات أساسية بنسبة 100% (اللغة العربية، طبقة التخزين الموحدة ومطابقة MicroSD/SAF، إدارة الملفات، كود التشفير، بصمة الوجه، تصنيف الفيديو وتوحيد التصنيفات، النقل الآمن والتراجع، درع الملفات المعطوبة، وخدمة المراقبة).*

exam-sorter/
├── main.py                     # نقطة الانطلاق وإدارة الشاشات السبع ودورة حياة التطبيق

│   ├── people_setup_screen.py
