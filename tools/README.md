# أدوات البناء والتطوير (Build & Packaging Tools)

يحتوي هذا المجلد على السكربتات المساعدة في تجميع وبناء ملف حزمة أندرويد (APK) عبر بيئة WSL:

1. **`build_apk_wsl.sh`**:
   - يقوم بنسخ ملفات التطبيق بأمان إلى نظام ملفات Linux ext4 السريع (`/root/build_wasaet`).
   - يستثني ملفات المستخدم والوسائط الخاصة (`الملفات المنظمة`, `docs`, `tools`, etc.).
   - يستدعي سكريبت التصحيح `patch_p4a.py` ثم يشغل Buildozer.
   - ينسخ الـ APK الناتج مباشرة إلى مجلد `bin/`.

2. **`patch_p4a.py`**:
   - يتحقق من توافق حزم Python-for-Android و KivyMD 2.0 مع إصدار بايثون 3.11 وحزم المعمارية الحديثة `arm64-v8a`.

3. **`build_wsl.log`**:
   - ملف سجل عمليات بناء الحزم للتشخيص عند الحاجة.
